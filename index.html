ARZA Backup VPS

A personal recovery-copy utility for the owner of the ARZA application. It runs on the owner's server and creates encrypted recovery archives containing application files, configuration and a consistent copy of application data.

The owner can authorize this utility to save encrypted archives to their Google Drive. It requests only the drive.file permission, which limits access to specific files used with this application. This is not a public sign-in or backup service; no other users are invited to connect accounts.

After uploading an archive, the utility reads its encrypted bytes back and checks the SHA-256 checksum. The private decryption key is kept separately by the owner and is not sent to Google Drive.
