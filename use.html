Use and operation

ARZA Backup VPS is configured for the server owner's personal recovery workflow. It does not accept public registrations, provide a paid backup service, or invite other people to authorize Google accounts.

The owner authorizes a specific Google Drive account and controls the server, archive retention and decryption keys. The utility must be used only with data and accounts that the owner is authorized to back up. Its Google permission is limited to files used with this application.

Backups can fail if the server is unavailable, storage is full, authorization is revoked or Google APIs are unavailable. The server records whether export, upload and checksum verification succeeded. Recovery requires the owner's private key and a separate restore procedure. Keeping that key available and private is essential.
